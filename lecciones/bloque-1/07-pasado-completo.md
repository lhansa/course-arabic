## Idea clave

El pasado no lleva prefijos. La forma de هو es la base desnuda y las demás personas solo añaden sufijos, que ya llevan dentro el pronombre.

## Paradigma

Raíz ك-ت-ب:

| Persona | Forma | Sufijo |
|---|---|---|
| أَنَا | كَتَبْتُ | ـْتُ |
| أَنْتَ | كَتَبْتَ | ـْتَ |
| أَنْتِ | كَتَبْتِ | ـْتِ |
| هُوَ | كَتَبَ | — (base) |
| هِيَ | كَتَبَتْ | ـَتْ |
| نَحْنُ | كَتَبْنَا | ـْنَا |
| أَنْتُمَا | كَتَبْتُمَا | ـْتُمَا |
| هُمَا (m) | كَتَبَا | ـَا |
| هُمَا (f) | كَتَبَتَا | ـَتَا |
| أَنْتُمْ | كَتَبْتُمْ | ـْتُمْ |
| أَنْتُنَّ | كَتَبْتُنَّ | ـْتُنَّ |
| هُمْ | كَتَبُوا | ـُوا |
| هُنَّ | كَتَبْنَ | ـْنَ |

## Explicación

Es el espejo del presente: allí la persona se marca sobre todo delante y aquí solo detrás. Los sufijos con ت (ـْتُ، ـْتَ، ـْتِ، ـْتُمَا، ـْتُمْ، ـْتُنَّ) corresponden a yo y a las personas de «tú/vosotros». El de هِيَ (ـَتْ) se escribe igual que el de أَنَا (ـْتُ) y solo se distingue por las vocales.
