## Idea clave

El presente se construye con 4 prefijos (أ، ن، ي، ت, «أنيت»), que marcan aproximadamente la persona, y unos pocos sufijos que precisan número y género. No son 13 formas sueltas.

## Paradigma

Raíz ك-ت-ب:

| Persona | Forma | Prefijo + sufijo |
|---|---|---|
| أَنَا | أَكْتُبُ | أ + ـُ |
| نَحْنُ | نَكْتُبُ | ن + ـُ |
| أَنْتَ | تَكْتُبُ | ت + ـُ |
| أَنْتِ | تَكْتُبِينَ | ت + ـِينَ |
| هُوَ | يَكْتُبُ | ي + ـُ |
| هِيَ | تَكْتُبُ | ت + ـُ |
| أَنْتُمَا | تَكْتُبَانِ | ت + ـَانِ |
| هُمَا (m) | يَكْتُبَانِ | ي + ـَانِ |
| هُمَا (f) | تَكْتُبَانِ | ت + ـَانِ |
| أَنْتُمْ | تَكْتُبُونَ | ت + ـُونَ |
| أَنْتُنَّ | تَكْتُبْنَ | ت + ـْنَ |
| هُمْ | يَكْتُبُونَ | ي + ـُونَ |
| هُنَّ | يَكْتُبْنَ | ي + ـْنَ |

## Explicación

El prefijo da una primera pista de la persona: أ para yo, ن para nosotros, ي para él y ellos, ت para tú y ella. El sufijo cierra la ambigüedad: ـِينَ (tú, femenino), ـَانِ (dual), ـُونَ (plural masculino), ـْنَ (plural femenino). Sin sufijo, ت puede ser «tú» (masculino) o «ella», y solo el contexto lo resuelve.
